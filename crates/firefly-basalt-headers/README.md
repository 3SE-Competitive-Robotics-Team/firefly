# firefly-basalt-headers

Basalt primitive translations. Source paths are preserved below `src/` and identified
in each translated module. The reference is revision
`aa441ba3e51050c47ba1902537792a2e4db7e43d`, pinned by the vcpkg port in
original Basalt `0f3b2b52c807f70ff4e2973ce253c73329eea7bc`.

Source: <https://gitlab.com/VladyslavUsenko/basalt-headers>.
Development and validation conventions: [development guide](../../docs/development.md).
The presence of this crate does not establish full upstream coverage or dataset equivalence.
