# 深度传感器模型与占据地图

## 数据流与约定

Bevy 深度预通道 → GPU 回读 → `z = near / reverse_z` → CPU 退化模型 →
`Firefly/Depth`。深度是相机光轴 Z（米），不是点到相机的欧氏距离。无效值为零。
在线与 `render --offline` 使用同一模型；RGB/灰度图不经过深度退化。

实现：`apps/render/src/depth_noise.rs`；配置入口：`configs/render.toml` 的
`[depth_noise]`。缺省参数由 `DepthNoiseOptions::default()` 提供，非法参数启动失败。

## 参考与适用范围

- [SimKinect 作者实现](https://github.com/ankurhanda/simkinect/blob/master/add_noise.py)：
  给渲染深度施加像素位置扰动、视差处理和量化。它针对 Kinect 结构光；本模型只参考
  像素扰动和视差建模思路，没有复制散斑模板、窗口过滤或其相机标定。
- [Nguyen / Izadi / Lovell，2012](https://users.cecs.anu.edu.au/~nguyen/papers/conferences/Nguyen2012-ModelingKinectSensorNoise.pdf)：
  区分轴向与横向噪声，实测表明距离和入射角影响噪声。该文的 Kinect 拟合参数不能
  直接作为当前虚拟相机的标定。
- [RealSense D400 深度后处理说明](https://dev.realsenseai.com/docs/depth-post-processing-for-intel-realsense-depth-camera-d400-series/)：
  三角测距深度噪声随距离平方增长；空洞还来自遮挡、无纹理、重复匹配、曝光和近距限制。
  文档采用 1/32 像素视差单位，也提醒导航不宜随意填洞。

这是**未用实机数据标定的双目代理模型**。空间/时间相关高斯场与概率门限是本项目的
简化设计，用来测试相关误差和不规则缺测，不是上述论文的完整复现。模型没有模拟
IR 散斑、材质反射率、透明/镜面、多径、真实双目遮挡几何、入射角依赖或匹配网络。
只输入一张几何深度图，无法判断白墙究竟有没有足够红外纹理。

## 数学与处理顺序

1. 量程裁剪：默认有效 `0.2 ≤ z ≤ 8m`，NaN、无穷大、超量程归零。
2. 从干净几何的 5×5 邻域识别跳变：差值超过 `max(0.12m, 0.04z)`，或邻域存在
   无效几何，则标记边缘。不能用已加噪的数据反推这张掩码。
3. 块状缺测：独立高斯格点以双线性方式插值，权重按平方和归一化，得到边际标准正态
   场 `g(u,v,t)`。格点默认相隔 8px；`g = √0.98 g_fixed + √0.02 g_dynamic(t)`，
   固定场与时变场独立。时变场相邻时间格点（间隔 0.4s）按方差归一化插值，
   静止时空洞主体固定，边界保留小幅抖动。
   用 `Φ(g) < p` 判失效，因此边际失效率为 p，但相邻像素倾向一起失败。
   平面 `p = min(1, 0.03 + 0.20(z/8)²)`；边缘为 `1-(1-p)(1-0.65)`。
4. 两个独立相关场生成横向扰动，默认标准差 0.5px；最近邻采样真实前/后景深度，
   不在线性插值中制造夹在两个物体中间的表面。原本无效像素保持无效。
5. 视差退化：`d=fB/z`，默认 B=0.05m。
   `ε=σ_d(√ρ g_d + √(1-ρ)η)`，ρ=0.5，η 为独立标准正态，σ_d=0.08px。
   `d_m=q round((d+ε)/q)`，q=1/32px，`z_m=fB/d_m`。
   非正视差和超量程输出归零，不能夹到某个合法远平面。

一阶误差传播：`∂z/∂d = -z²/(fB)`，故 `σ_z ≈ z²σ_d/(fB)`。
当前 f≈168.6px，在 1m 处约 9.5mm，4m 处约 152mm（不含量化、裁剪、失效与横向误差）。
这些数值说明分辨率和基线直接影响精度，并非越加花纹越真实。

种子默认 20261002。相同配置、几何与测量时间产生相同输出；场只随测量时间变化，
不随工作线程队列长度变化。时间相关性作用于噪声场，不复用历史深度，不模拟拖影。
场固定在图像坐标中，不能解释为随场景表面运动的材质缺陷。

## 配置与复现

默认启用，无须添加默认键。可以在 `configs/render.toml` 添加覆盖，例如：

```toml
[depth_noise]
seed = 42
patch_size_px = 12
```

`enabled=false` 关闭随机退化，但保留量程裁剪；`disparity_step_px=0` 关闭量化。
参数单位和完整列表在 `DepthNoiseOptions`；`temporal_fraction` 是相关场的时变方差比例，
不是空洞概率。离线 `render --offline` 提供理想几何深度标签，不施加在线测量退化，
仍需向左目注册并拒绝遮挡边缘。视觉库兼容条件只包含场地、标定、光照和传感器曝光；
二进制和源码 hash 记录生成来源，在线噪声变化不要求重建资产。不得修改历史 manifest
冒充同一批采集。CAD 静态占据图同样不依赖测量噪声。

验证命令：

```bash
cargo test -p render --bin render
cargo test -p firefly-map depth::tests
```

测试覆盖独立视差解析值、有限差分导数、距离平方误差增长、量化、不规则缺测的相邻
相关性与时间相关性、边界缺口、固定种子重现、无效值和最终量程契约。它们验证模型
实现，不证明模型已经匹配某款实机。实机标定应在多个距离和倾角采集平面与遮挡边界，
比较深度偏差/RMS、失效率、孔洞尺寸、边缘位置分布和相邻帧相关性。

## 深度如何参与避障

```text
STP → 归一化几何 → rmuc2026.ffmap ───────────────┐
                                              ↓
深度 + 同时刻 CorrectedOdometry → 射线更新 → 占据体素 → 膨胀 → 规划/轨迹检查
```

- planner 启动读取 `apps/planner/maps/rmuc2026.ffmap`，缺文件报错；当前场地文件体素
  分辨率 0.15m。这是 CAD 先验占据图，区别于供 ALIKED/LightGlue 检索的 `.ffvmap`。
- 在线深度默认每隔 3px 取射线，最大光轴深度 8m。使用插值到深度时间戳的地图系里程计
  和相机外参投影；沿途降低占据 log-odds，末端提高。无效深度完全跳过。
- 规划使用更新后的膨胀障碍。默认膨胀参数 0.2m，在 0.15m 格上取整为两格；这是
  离散轴向扩展，不是任意误差下的安全保证。路径搜索/轨迹优化之后，最终静态检查用
  Bernstein 凸包与递归分割覆盖轨迹；执行期检查未来轨迹，触发重规划或急停。
- 深度/里程计超时有停止机制，但“按时收到一张全空深度图”和“获得有效观测”目前
  没有通过独立有效像素覆盖门槛区分。

### 当前安全边界

1. 先验与在线观测共用一个可修改的 log-odds 层。`static_occupied` 仅保护动态障碍
   删除操作，深度 miss 与周期衰减没有通用的先验保护。错误射线有可能削弱静态障碍。
2. 未观测格初始为 Free，地图窗口外占据查询也返回未占据（虚拟墙除外）。未知不是
   已验证的自由空间；碰撞检查继承这个地图语义。
3. 每条像素射线独立累计，帧内没有按体素合并证据。相关深度噪声不能被当成多份
   独立测量；位姿误差也会让整张深度投影错位。

因此，先验地图、在线深度和碰撞检查都存在，但不能据此承诺不碰撞。地图层的优先
改进方向是独立保护静态先验、明确 unknown/free/occupied、帧内合并观测，以及为深度
有效覆盖增加健康判据；这不属于深度噪声参数调整。
