# VOID 机动漂移问题——根因与架构分析（高质量 context）

> 本文档是 firefly-void 机动漂移问题的**权威记录**，供后续轮次/会话作为 context 使用。
> 所有结论均来自 P10.x 系列**实测取证**（探针/e2e），非推测。数据在 `logs/p10_*/`。
> 更新时保持精简、结论先行，删除过期内容。

## 一句话结论

**VOID（深度单目+稠密地图+ESIKF）在机动时漂移 4-7m 的根因是：自举地图跟随估计漂移，失去世界锚定——窄 FOV 深度相机灌密点导致平面 1-4 帧冻结跟漂，深度/视觉都锚在会漂的地图上，无独立绝对参照。**

## 关键数字（实测，首点对齐口径）

| 指标 | VOID | VIO（MSCKF） | 说明 |
|---|---|---|---|
| 悬停 ATE-RMS | 0.075±0.018m | 0.0014±0.0001m | VIO 好 53× |
| 李萨如 ATE-RMS | 4-7m（7.55±2.23 实测） | 1.79±0.19m | VIO 好 4.2× |
| 机动 depth_ok | 2-3%（**指标假象**） | — | 见下 |
| 悬停 depth_ok | 97-99% | — | 深度全效 |

**depth_ok 是误导性指标**：稠密深度点云下官方收敛阈值（1.5e-4m）物理不可达（P10.14），
不代表深度失效——深度匹配 82% 成功、修正照常应用。看 kept 点数/残差才有物理意义。

## 根因链（P10.x 实测逐环确认）

1. **地图自举**：地图点位置由「当前估计状态投影的深度点」注册决定（注册用更新后状态，与官方一致）。
2. **窄 FOV 灌密点**（P10.16 实测）：2250 点/帧挤进 ~170 个 0.5m 体素 → **每体素 ~13 点/帧**（官方 LiDAR 大视场 ~1-2 点/帧）。官方 24000 点散布全视场，我们同量级点挤窄视场。
3. **平面快速冻结+持续 refit**（P10.15 实测）：机动中平面 **100% 未成熟**（npts 恒 35-47，未达 50 冻结阈值），持续 refit 吸收最新点 → **平面位置 ≈ 估计状态的时间平均**。
4. **无误差信号**（P10.15 实测）：平面中心与估计位置**相关系数 x=0.99/y=0.92**，两者一起漂 4m+；深度点投影到被拖走的平面，残差恒 ≈0（实测 mean -0.3cm）→ ESIKF 无纠正信号 → 深度失去绝对锚定。
5. **视觉无独立锚定**（P10.15 分离实验）：禁视觉 4.13m ≈ 基线 4.44m——视觉点也锚在漂移地图上。
6. **悬停好**：无运动激励，平面自然锚准（0.04-0.06m）。

## 与官方 FAST-LIVO2 的关键差异

| 项 | 官方（LiDAR） | 我们（深度相机） | 影响 |
|---|---|---|---|
| 单帧总点数 | 24000 原始→去重后数千（**无"500"这回事**，P10.16 纠移植误记） | 2250 | 同量级 |
| 观测视场 | 360° 全视场（MID-360/Avia） | ~70° 窄 FOV 单侧 | **几何单一 + 点集中** |
| 单帧单体素注入 | ~1-2 点（散布） | ~13 点（实测） | 平面冻结快 4-25 倍 |
| 平面冻结帧数 | ~25-50 帧（跨帧平均稀释误差） | ~4 帧（跟漂） | 无绝对参照 |
| 地图注册时机 | 更新后状态（一致） | 更新后状态 | 无差异（排除滞后） |

**代码机制逐行同构**（octree.rs ↔ voxel_map.cpp：0.5m 根体素+八叉、refit、50 点冻结、
layer_init 5）。唯一差异是**单帧单体素注入率**，源于**观测几何**（视场宽度），非参数 bug。

## 架构本质（VIO vs VOID 差异的根）

- **VIO（MSCKF）**：滑动窗口多视图，特征窗口内独立三角化，**不建地图、无长时记忆** → 无地图漂移问题。
- **VOID**：稠密地图自举，所有测量锚定在地图上 → 地图是**可漂移的参照系**。
- **FAST-LIVO2 隐含前提**：LiDAR 360° 全视场 + 点注册精度高 → 地图是可靠绝对参照。窄 FOV 深度相机破坏该前提，却保留"锚定地图"用法 → 地图漂移成灾难。
- **悬停/近静态 VOID 好**（地图自锚），**机动 VOID 差**（地图跟漂）；VIO 两场景都稳。

## 未验证的方向（下一步候选）

1. **深度做局部/帧间约束**：不依赖全局地图锚定，利用深度"绝对测量"性质做帧间/局部约束（类似 MSCKF 滑动窗口），避免地图跟漂。
2. **视觉提供独立锚定**：目前视觉点锚在漂移地图上（禁视觉≈基线）——若视觉能提供与地图无关的约束（如滑动窗口特征），可救 x/y。
3. **扩大观测几何**：更大 FOV / 多相机摊薄注入（P10.16 建议，未验证）。
4. **接受物理限制**：单目深度窄 FOV 有天花板，VIO 为主、VOID 定位升级线（先验地图场景）。
